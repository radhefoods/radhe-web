## Documentation

The shop is documented in `docs/`. Start at `docs/README.md`; the state of every feature is in `docs/features/README.md`, the working rules in `docs/development/conventions.md`.

A change to a feature changes its document in the same commit (`docs/development/documentation-standard.md`), and `node docs/tools/check-docs.mjs` must pass.
